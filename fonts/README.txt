SELF-HOSTED FONTS INCLUDED

This release includes official variable font files and matching SIL Open Font License 1.1 notices in this folder.

- Bricolage Grotesque: BricolageGrotesque[opsz,wdth,wght].ttf
- Instrument Sans: InstrumentSans[wdth,wght].ttf

Both families load locally with @font-face and font-display: swap from design-system.css. No remote font service is required. Keep the licence notice files when redistributing this template. See docs/ASSET-LICENCES.md for upstream details.
