START HERE

Make the template your own.

This static HTML/CSS/JavaScript template requires no build step. Work on a copy, replace placeholders, and test everything before publishing.

01 / GET STARTED

Open the files

  1. Download the repository ZIP and extract it.
  2. Open index.html in a modern browser.
  3. For realistic testing, serve the folder with a local static server.
02 / RENAME THE BRAND

Find “Your Brand”

Use Find & Replace for the exact placeholder, then check page titles, meta tags, canonical URLs, logo text, footer, contact copy, and licence. Review each replacement before publishing.

03 / COLOURS AND FONTS

Edit design tokens

Change CSS variables in design-system.css, including --brand, --paper, --ink, --accent, and --brand-soft. The repository includes self-hosted Bricolage Grotesque and Instrument Sans variable fonts under /fonts, loaded locally with font-display: swap.

04 / CONTACT FORM

Configure Formspree

Replace YOUR_FORM_ID in contact.html with your real Formspree form ID. Configure the thank-you redirect in the provider dashboard, then test a submission. Never put API secrets in public front-end files.

05 / DEPLOY

Publish a tested copy

For GitHub Pages, use a repository and branch supported by your account settings. For Netlify, upload the static folder or connect a repository. Set your real domain in canonical tags, sitemap.xml, robots.txt, and the form redirect. Public repositories expose source code.

06 / FONTS AND LICENCES

Check every asset

This version uses CSS/SVG artwork and no stock photos. The two local font files and their SIL Open Font License notices are included under /fonts. Keep those notices with the package and review docs/ASSET-LICENCES.md for source details.
