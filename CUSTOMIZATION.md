# AETHER® Multi-Agency Template — Setup Guide

## What this package is

A static HTML/CSS/JavaScript website starter intended for creative agencies and other service businesses. It is designed to be edited, branded, tested, and adapted before client or commercial use. It is not a hosted SaaS product and does not require a build step.

## Pages

- `index.html` — agency homepage
- `services.html` — service list and details
- `work.html` — portfolio/concept case studies
- `about.html` — studio story and principles
- `pricing.html` — engagement models and FAQs
- `contact.html` — enquiry form demo
- `niche-starters.html` — eight agency/business directions
- `customizer.html` — live colour, brand-name, and headline preview with CSS-token output
- `styles.css` — shared visual system and responsive layouts
- `script.js` — mobile navigation, reveal animation, year, and email-draft form handling

## Quick start

1. Download the project ZIP from GitHub, or clone the repository.
2. Extract the folder.
3. Open `index.html` in a modern browser. A local static server is recommended for testing.
4. Open `customizer.html` to try colour and copy directions.

## First customisation

1. Search the project for `AETHER` and replace it with the purchased brand name.
2. Edit the global design tokens near the top of `styles.css`: `--ink`, `--paper`, `--lime`, and `--muted`.
3. Update headings, services, calls to action, navigation, page titles, meta descriptions, and social links on each page.
4. Replace concept work with genuine projects and correctly licensed imagery.
5. Update the email target `hello@example.com` in `script.js` and `contact.html`.
6. Test keyboard navigation, mobile layouts, colour contrast, broken links, image loading, and forms.

## Contact form limitation

The included contact form uses a `mailto:` link. It opens the visitor's configured email app and does not send to a server or store submissions. Connect a reputable form service or your own backend if direct form submission is required.

## Images and fonts

The demo uses remotely hosted Unsplash image URLs and Google Fonts. Confirm the current licence/terms and network behaviour for your intended use, or replace the images and self-host licensed assets before client work or resale. Do not imply that sample projects are real clients.
